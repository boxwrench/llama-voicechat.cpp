# AMD VoiceChat research

This directory records AMD/Linux bring-up and measurement work for NemotronLabs VoiceChat 11B.

The current reference is Q8_0 on the AMD Radeon AI PRO R9700 (`gfx1201`). The first complete AMD speech-to-speech bring-up is commit `38a76719e2b31a4dfc574bf750bb9ad44c434b81` on branch `amd/q8-bringup`.

The first measured reference is under `baselines/R9700-Q8-M1`. It measures the existing runtime before microphone integration or optimization.
